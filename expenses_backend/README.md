# secure-expenses
API para registrar as despesas/receitas pessoais.

Objetivo:
    API desenvolvidade em Node.js para gerenciamento de despesas/receitas pessoais, que permite registrar, listar,
    atualizar e remover despesas/receitas.
Tecnologias:
    Node.js
    Express
    Git
    Postman

Dependencias:
Node
Express, Sequelize, MySQL e Multer.
Xampp

Iniciando a API

Baixe as dependencias com:
    npm i
Crie um arquivo .env dentro da pasta de expenses_backend seguindo o exemplo do .env.example.
Lembrando que o banco já precisa estar criado, para podermos colocar o nome no .env, mas as tabelas e campos serão criados automaticamente.

E por fim execute:
    npm run dev
A seguinte mensagem deve aparecer no seu terminal:
    Servidor rodando em http://localhost:3000
